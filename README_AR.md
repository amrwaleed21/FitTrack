# FitTrack — النسخة الشخصية أوف لاين

تطبيق شخصي لتسجيل السعرات والوجبات والمياه والنوم والتمارين وقياسات الجسم، دون حسابات أو سيرفرات أو مزامنة. البيانات تُحفظ محليًا على نفس الجهاز باستخدام تخزين المتصفح.

## التشغيل
1. افتح `index.html` في متصفح حديث.
2. أدخل بياناتك الشخصية أول مرة، ثم ابدأ تسجيل وجباتك ونشاطك.
3. للتثبيت كتطبيق والعمل أوف لاين بشكل موثوق، ارفع المجلد على استضافة ملفات ثابتة (Static Hosting) وافتحه مرة واحدة بالإنترنت ثم ثبّته على الشاشة الرئيسية.

## ملاحظات مهمة
- لا يوجد تسجيل دخول ولا اتصال بقاعدة بيانات ولا مزامنة بين الأجهزة.
- تسجيل البيانات الأساسية يعمل محليًا؛ خرائط الشوارع وتحليل صورة الطعام بالذكاء الاصطناعي غير متاحين في النسخة الشخصية دون خدمات خارجية.
- لا تمسح بيانات المتصفح إذا أردت الاحتفاظ بسجلاتك.


## تحديث التصميم
- تحديث ألوان الواجهة إلى الأخضر المتناسق مع أيقونة FitTrack.
- إضافة شعار CementFit المرفق في تبويب التمرين.
- إضافة خانة للاسم الشخصي وعرض «أهلًا [اسمك]» بعد حفظ بياناتك.
